Describe it once, as an enum.
Get a database you can read.

Imagile.Framework is a set of .NET 10 packages where annotated enums are the source of truth for your domain vocabulary — and the framework turns them into seeded lookup tables, audited entities, and convention-checked schemas.

You writeOrderStatusType.cs
public enum OrderStatusType
{
    [Description("Awaiting payment")]
    [Category("Open")]
    Pending = 1,

    [Description("Payment received")]
    [Category("Open")]
    [Requires<PaymentType>(PaymentType.Card,
                           PaymentType.Invoice)]
    Paid = 2,

    [Description("Shipped to customer")]
    [Category("Closed")]
    Shipped = 3,
}

One loop, end to end

Each package strengthens the same cycle — the enum feeds the schema, the schema stays honest under test, and the application layers above inherit the vocabulary.

enum + attributes→ seeded schema→ audited entities→ convention tests→ Blazor telemetry

Packages

Six focused packages. Core has zero dependencies; everything else builds on it.

Imagile.Framework.Core

Zero-dependency attributes and extensions for describing domains with enums: [Category], [Requires], [Includes], [Associated], flag helpers, and metadata lookups.

Imagile.Framework.EntityFrameworkCore

Enum-seeded lookup tables, reference-entity upsert, automatic Created/Modified auditing with property-level change tracking, soft delete with global query filters, and tenant scoping.

Imagile.Framework.EntityFrameworkCore.Testing

Database readability as a test suite: naming-convention rules (plural PascalCase tables, Id primary keys, no nullable booleans, max lengths on strings) that fail your build before they reach a migration.

Imagile.Framework.Configuration

Key Vault reference resolution (@KeyVault(SecretName)), AppTokenCredential for Azure auth, and fail-fast configuration validation.

Imagile.Framework.Storage

Type-safe Azure Queue and Blob abstractions — implement IQueueMessage or IBlobContainer and the framework names, registers, and creates the resources.

Imagile.Framework.Blazor.ApplicationInsights

Application Insights for Blazor WebAssembly: automatic page tracking, error boundaries, ILogger shipping, and custom telemetry initializers.

Install

Packages target .NET 10 with Native AOT and trimming analysis enabled.

# start with the zero-dependency core
dotnet add package Imagile.Framework.Core

# add the pieces you need
dotnet add package Imagile.Framework.EntityFrameworkCore
dotnet add package Imagile.Framework.EntityFrameworkCore.Testing
dotnet add package Imagile.Framework.Configuration
dotnet add package Imagile.Framework.Storage
dotnet add package Imagile.Framework.Blazor.ApplicationInsights
